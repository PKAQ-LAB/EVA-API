# 菜单动作键与按钮权限

2026-11-01，唯一总控统合部。用户已批准独立字段、菜单字符串资源及 Umi Access 方案；本卡仅记录此任务，不扩大现库写入、服务重启或发布授权。

## 实施契约

- 资源增加可空 ACTION_KEY，管理接口字段为 actionKey；保留原 ID、CODE、HTTP 方法、路径和角色资源授权关系。
- fetchMenus 的每个菜单 resources 返回当前有效授权资源的非空动作键，有序去重为字符串数组；管理及角色授权接口仍返回资源对象。
- 内置动作使用 list、read、create、update、delete；read 仅详情。自定义动作不含模块前缀，同名动作按菜单隔离。
- 前端复用 Umi Access，迁移旧 HTTP/path 按钮判断；保留记录状态、9999、字典分类与日志管理员等业务限制。
- 数据权限开关上一轮改动完整保留。关闭资源权限不等于关闭认证、数据权限或业务保护。
- 不从历史 CODE、HTTP 方法、通配路径或中文名称推导 CRUD，不自动给角色增加授权。
